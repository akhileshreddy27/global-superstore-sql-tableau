# Tableau Dashboard — Global Superstore

Workbook: [`tableau/Global_Superstore_Dashboard.twbx`](tableau/Global_Superstore_Dashboard.twbx)
(generated by `scripts/build_tableau_workbook.py` and tested by opening it in Tableau Public 2026.1).

## Data source

`tableau/superstore_tableau_source.csv` is the MySQL view `v_orders_enriched` (see
`sql/04_tableau_view.sql`), exported by `scripts/run_sql.py`. It is line-level (51,290 rows), with
Returns and People already joined in SQL, plus derived fields:

| Field | Meaning |
|---|---|
| `Returned` | `Yes` if the order is in Returns, joined on Order ID + Market |
| `Returns Tracked` | `Yes` for the 4 markets that record returns |
| `Regional Manager` | from People |
| `Market Region` | `Market - Region`, because Central / North / South repeat across markets |
| `Discount Band` | 0%, 0-10%, 10-20%, 20-30%, 30-50%, 50%+ |
| `Ship Days` | `Ship Date - Order Date` |

## Calculated fields (in the workbook)

| Name | Formula |
|---|---|
| Profit Margin | `SUM([Profit]) / SUM([Sales])` |
| Average Order Value | `SUM([Sales]) / COUNTD([Order ID])` |
| Orders | `COUNTD([Order ID])` |
| Customers | `COUNTD([Customer Name])` |
| Returned Order | `IF [Returned] = 'Yes' THEN [Order ID] END` |
| Return Rate | `COUNTD(IF [Returned] = 'Yes' THEN [Order ID] END) / COUNTD([Order ID])` |

## Open the workbook

The data ships as a Hyper extract (`tableau/Data/superstore_extract.hyper`, built from the MySQL
export with Tableau's Hyper API), so the workbook opens without any database connection.

1. Install the free [Tableau Public desktop app](https://public.tableau.com/app/download), or use Tableau Desktop.
2. **File → Open…** and choose `tableau/Global_Superstore_Dashboard.twbx`.
   It opens on the Executive Overview dashboard.
3. Switch between the three dashboards with the tabs at the bottom. Click a bar on the
   market, sub-category or segment charts to filter the rest of that dashboard.

## Story to present

1. Sales nearly doubled (+90.3%) from 2011 to 2014, with year-end peaks every year.
2. Technology leads in sales and profit. Furniture sells almost as much at half the margin.
3. Five sub-categories make up 57.8% of sales.
4. Tables loses money overall ($64K loss), and the loss comes entirely from heavy discounting.
5. Above a 20% discount, margin flips from +21% to –42%: $815K of profit lost.
6. Return rates sit at 5–6% wherever returns are tracked. Three markets don't track them at all.
